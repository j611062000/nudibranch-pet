# 設計方向

[English](DESIGN.en.md) | **繁體中文**

## 角色

使用單色剪影，融入 macOS 原有選單列圖示。身體像麻糬般短胖，頭部圓潤、尾巴短，兩支短觸角與背部小鰓叢保留海蛞蝓特徵。小尺寸下優先確保輪廓可讀，眼睛和笑容可以視可讀性簡化。

`monochrome-chubby-concept.png` 是目前選定方向的 AI 生成概念圖，不是正式圖示資產，也不是 App 截圖。實作時應重新繪製適合小尺寸與透明背景的角色，不能直接把整張概念圖當成選單列素材。

## 活動範圍

使用原生 `NSStatusItem` 保留一段固定寬度的區域。角色所有部位都必須留在這個區域與選單列高度內。碰到左右邊界時轉身，不能跨越或遮蓋其他應用程式的圖示。

第一版不使用桌面浮動覆蓋層；也不沿整條螢幕頂端移動。確切區域寬度與角色尺寸需在實機檢查後決定。

Apple 的 [statusItem(withLength:) 文件](https://developer.apple.com/documentation/appkit/nsstatusbar/statusitem(withlength:)) 說明如何分配選單列項目的寬度。

## 動作與互動

- 慢爬：低速位移、輕微身體伸縮與觸角晃動。
- 轉身：到達邊界後改變方向。
- 休息：趴低、閉眼、暫停位移。
- 點擊：打開餵食、摸摸、睡眠與結束 App 的控制面板。
- 配合系統減少動態效果設定，提供靜態模式。
- 收起互動面板時停止場景動畫；選單列的更新頻率需量測後調整。
- 互動面板預計支援繁體中文與英文；目前原型僅有繁體中文。

## 發布前仍需驗證

1. 原生選單列啟動、點擊與結束流程。
2. 在淺色／深色選單列、不同縮放比例下的可讀性。
3. 自動隱藏選單列、全螢幕、多螢幕與瀏海螢幕行為。
4. 休眠喚醒、重新啟動後的狀態與互動冷卻。
5. 常駐 CPU 與能源使用、減少動態效果與鍵盤操作。
6. `.app` 打包；若對外提供下載，再處理簽署與公證。
